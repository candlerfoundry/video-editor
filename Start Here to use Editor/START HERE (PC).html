1 Install Python one time · ~3 min ▾
This puts Python on your own computer. Follow these exactly:
  1. Click Download Python below to open python.org.
  2. Do NOT click the big yellow “Download Python install manager” button. That installs only a helper tool, not Python itself.
  3. Instead, click the link that shows a version number, like “Python 3.14.6”, under “Or get the standalone installer.” See the picture below.
  4. Open the file that downloads (it appears at the bottom of your browser).
  5. On the installer's first screen, check the box “Add python.exe to PATH” at the bottom, then click Install Now. Keep the default location — don't change it to Dropbox.
  6. When it says “Setup was successful,” click Close. Done.

2 Install Dropbox one time ▾
Install the Dropbox desktop app and sign in with the Foundry's Dropbox account — the login credentials are in the PTE folder. The main Dropbox website doesn't show an obvious install button, so go straight to dropbox.com/install. After it installs, wait until the Foundry Video Editor folder shows a green check mark (finished downloading). Dropbox pulls in videos only as you need them — just this folder has to be synced.
Install Dropbox ↗
3 Make a desktop shortcut one time ▾
In Dropbox, open the Foundry Video Editor folder and find Foundry Video Editor.exe (shown below). This is the app you'll open every time. Right-click it and choose Send to → Desktop (create shortcut) so it's easy to find later. On Windows 11 you may need to click “Show more options” first.

Every time you want to edit
4 Open the app ▾
Double-click your “Foundry Video Editor” desktop shortcut. A small window opens and gets the backend ready (the first run can take a few minutes). When it says “Backend running,” click the orange Open Video Editor button — the editor opens in your browser. Leave that small window open while you work.
5 Edit ▾
Work in the editor tab that opened in your browser. When you're done, close the small launcher window to shut everything down.

If something goes wrong

The window says “Python not found”
Python isn't installed yet — do Step 1, then open the app again.
It says “server.py not found” or won't start
Dropbox hasn't finished syncing. Wait for the green check mark on the Foundry Video Editor folder, then try again. (Also make sure you used a shortcut and didn't move the .exe out of the folder.)
The browser opens but the editor can't connect
Close the launcher window and open the app again. Make sure nothing else is using port 5000.
Still stuck
Send Emily a screenshot of the launcher window.
