Foundry Video Editor — Mac Setup

Two one-time steps, then it's a double-click forever.

The Windows app won't run on a Mac, so on a Mac you start the editor with the files below. You run a setup once (it installs everything for you), and after that you just double-click to open the editor.
First time only — set up once
1
Install Dropbox & sign into Foundry one time
Install the Dropbox desktop app and sign in with the Foundry's Dropbox account (credentials are in the PTE folder). Wait until the Foundry Video Editor folder shows a green check mark, which means it has finished downloading.
Get Dropbox ↗
If a second Dropbox account is already on this Mac, the editor still finds the Foundry folder automatically — you just need the Foundry account signed in and synced.
2
Run the setup, once one time · ~10 min
This installs everything the editor needs. Open the Terminal app (press ⌘ Space, type “Terminal”, press Return). Then type bash followed by a space, drag the file “Setup (Mac).command” into the Terminal window (it fills in the path), and press Return.

It may ask for the Mac password and will take several minutes — that's normal. When it says “Setup complete,” you're done with setup forever.
Every time you want to edit
3
Open the app
Setup created a launcher at ~/Applications/Foundry Editor.command. Double-click it — a small window opens, gets things ready, then the editor opens in your browser automatically. Leave that window open while you work; close it when you're done. Tip: drag that file onto your Dock so it's one click from now on.
⚙️ ~/Applications/Foundry Editor.command double-click
First launch only: if macOS says “unidentified developer,” right-click the file → Open → Open. This launcher lives outside Dropbox, so it keeps working even after the team updates the editor.

If something goes wrong

“…could not be executed because you do not have appropriate access privileges”
Dropbox dropped the launcher's “executable” mark (this can happen after the team updates the editor, and macOS gives no way to restore it from Finder). Re-run Setup (Step 2) — it's run with bash, so it works even when the mark is missing, and it reinstalls a permanent launcher at ~/Applications/Foundry Editor.command that doesn't have this problem. Launch from that file afterward.
The launcher opens in TextEdit instead of running
Setup hasn't finished, or it didn't bless the launcher. Re-run Step 2, or right-click the launcher → Open.
“Could not find server.py”
Dropbox hasn't finished syncing the Foundry account. Wait for the green check mark on the Foundry Video Editor folder, then try again.
It warns “ffmpeg not found”
Re-run Step 2 (Setup installs ffmpeg).
Browser opens but the editor can't connect
Close the window and double-click the launcher again. Make sure nothing else is using port 5000.
Still stuck
Send Emily a screenshot of the Terminal window.
