Foundry Video Editor — Mac Setup

Two one-time steps, then it's a double-click forever.

The Windows app won't run on a Mac, so on a Mac you start the editor with the files below. Windows is NOT required — everything installs natively on your Mac. You run setup once, and after that you just double-click to open the editor.

First time only — set up once

1 Install Dropbox & choose your folders one time ▾
Install the Dropbox desktop app and sign in with the Foundry's Dropbox account (credentials are in the PTE folder). The main Dropbox website doesn't show an obvious install button — go straight to dropbox.com/install.
Install Dropbox ↗
  1. After Dropbox installs, a window asks which folders to show on this Mac. Choose ALL of them. They'll appear in Dropbox but won't download automatically, so they don't take up space.
  2. Right away, two-finger-click (or right-click) the “Scripts” folder and choose “Make available offline.” Do the same for the “Social Media Clips” folder. Nothing works properly unless these two are available offline.
  3. It's fine to leave everything else online only — when you pick a video to edit, Dropbox downloads it automatically.
  4. Wait until the Foundry Video Editor folder shows a green check mark (finished downloading).
If you didn't choose all folders, or can't see them later Turn on Full Disk Access for Dropbox: System Settings → Privacy & Security → Full Disk Access, then toggle Dropbox on.
2 Run the setup, once one time · ~10 min ▾
This installs everything the editor needs. First, find the Setup file here:
Dropbox›Scripts›Foundry Video Editor›Start Here to Use Editor
⚙️Setup (Mac).command← you'll drag this into Terminal
Open the Terminal app (press ⌘ Space, type “Terminal,” press Return). Then type bash followed by a space, drag the file “Setup (Mac).command” into the Terminal window (it fills in the path), and press Return.

What you'll see — stay at the computer until it finishes:
  1. It may ask for your Mac password (sometimes just a key icon). Type your Mac login password and press Return. Nothing shows up as you type — no dots or letters. That's normal Mac security; your typing is registering.
  2. Dozens of lines scroll by. If it pauses on “Press Return/Enter to continue or any other key to abort,” press Return.
  3. If it asks “…proceed? (y/n)”, type y and press Return.
  4. If a box appears saying “Terminal” wants to access files managed by “Dropbox,” click Allow.
  5. It takes several minutes — that's normal. When it says “Setup complete,” you're done with setup forever.
Every time you want to edit
3 Double-click “Foundry Editor” on your Desktop ▾
Setup put a Foundry Editor app (orange F icon) right on your Desktop. Double-click it — a small window opens, gets things ready, then the editor opens in your browser automatically. Leave that window open while you work; close it when you're done. Tip: drag the app onto your Dock so it's always one click away.
🟠 Foundry Editor on your Desktop · double-click
Because Setup builds this app right on your Mac, it opens with no security warning — just double-click. It lives outside Dropbox, so it keeps working even after the team updates the editor. (A backup launcher also exists at ~/Applications/Foundry Editor.command if you ever need it.)

If something goes wrong

The app/folder is empty, or files won't open
Make sure the Scripts and Social Media Clips folders are “available offline” (Step 1), and the Foundry Video Editor folder shows a green check mark. If folders are missing entirely, turn on Full Disk Access for Dropbox (Step 1 tip).
The “Foundry Editor” app is missing, or won't open
Re-run Setup (Step 2) — it rebuilds the Foundry Editor app on your Desktop and reinstalls the backup launcher at ~/Applications/Foundry Editor.command.
macOS says “Apple could not verify ‘Foundry Editor’ is free of malware”
This only happens to a copy you downloaded (e.g. from Slack) — not the one Setup builds. Run Setup (Step 2) and use the Desktop app it creates. To open a downloaded copy instead: click Done, then System Settings → Privacy & Security, scroll to Security, and click “Open Anyway.”
“…could not be executed because you do not have appropriate access privileges”
The Desktop Foundry Editor app doesn't have this issue — use it instead of any .command file, or re-run Setup (Step 2).
“Could not find server.py”
Dropbox hasn't finished syncing. Wait for the green check mark on the Foundry Video Editor folder (and confirm Scripts is available offline), then try again.
