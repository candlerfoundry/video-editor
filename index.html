This app needs a small helper program running on your computer to process video. Your team lead has already set this up in Dropbox — follow the steps below to get started.

  1. Make sure Python 3.14 is installed. Download from python.org and check "Add Python to PATH" during install.
  2. Open Dropbox → Scripts → Video Editor Downloads → foundry-video-editor-backend
  3. Double-click start_server.bat — a window opens and installs everything automatically
  4. Keep that window open and return here — this page will connect on its own
