This app needs a small helper program running on your computer to process video. Your team lead has already set this up in Dropbox — just follow the steps below.

  1. Make sure Python 3.14 is installed. If not, download it from python.org and check "Add Python to PATH" during install.
  2. Open Dropbox → Scripts → Video Editor Downloads → foundry-video-editor-backend
  3. Double-click start_server.bat — a window will open and install everything automatically
  4. Keep that window open and return here — this page will connect on its own
