Set up your local server

This app needs a small helper program running on your computer to process video. Your team lead has already set this up in Dropbox — follow the steps below.

  1. Make sure Python 3.14 is installed. Download from python.org and check "Add Python to PATH" during install.
  2. Open Dropbox → Scripts → Video Editor Downloads → foundry-video-editor-backend
  3. Double-click start_server.bat — a window opens and sets everything up automatically
  4. Keep that window open and come back here — this page will connect on its own
